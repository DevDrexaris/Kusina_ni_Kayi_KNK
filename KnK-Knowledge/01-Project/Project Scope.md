# Project Scope

**Evidence status:** VERIFIED in UI, API, schema, and [README.md](../../README.md).

## Implemented
- Customer account registration/login, product browsing, category browsing, saved delivery addresses, cart, COD checkout, order history/cancellation, and ratings.
- Staff active-order processing, rider assignment, order history, customer details, and notifications.
- Rider assignment list, availability, delivery status updates, and confirmation of delivery.
- Admin dashboard, order management, product/category management, team-account creation, and account moderation.

## Explicitly out of scope in the current implementation
- Online card/payment processing: COD is the only schema payment method.
- Maps, live GPS tracking, or external delivery service integration (README statement).
- Cloud services: README describes the deployment as local XAMPP.

Scope is not a roadmap. Do not represent unimplemented ideas as available features.
