# API Documentation

**Evidence status:** VERIFIED from `frontend/src/api.ts` and corresponding PHP action dispatch. Base path is `/api/`; development proxy is documented in [[Request Lifecycle]]. Unless noted otherwise, “GET” is an action read request.

| Endpoint                     | Frontend action and method                                                                                                                                                                                                                                                   | Authorization / effects                                                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auth.php`                   | `me` GET; `login`, `register`, `create_user`, `rider_availability`, `moderate_user` POST; `logout`, `riders`, `admin_users` GET                                                                                                                                              | Session restore; admin creates/moderates users; admin/staff can list riders; rider updates own availability.                                              |
| `products.php`               | `list`, `detail` GET; `save`, `delete` POST                                                                                                                                                                                                                                  | Listing/detail are public; save/delete require admin.                                                                                                     |
| `categories.php`             | `list` GET; `save`, `delete` POST                                                                                                                                                                                                                                            | Listing is public; mutations require admin.                                                                                                               |
| `addresses.php`              | `list` GET; `save`, `delete` POST                                                                                                                                                                                                                                            | Authenticated customer-owned saved addresses.                                                                                                             |
| `orders.php`                 | `create`, `status`, `assign`, `unassign`, `rider_status`, `staff_status`, `cancel` POST; `mine`, `all`, `staff_dashboard`, `staff_history`, `staff_customers`, `customer_details`, `staff_notifications`, `active`, `rider`, `cancellation_alerts`, `assignment_history` GET | Customer, staff, rider, and admin permissions vary by action; see `orders.php` dispatch and [[Authentication]].                                           |
| `ratings.php`                | `submit` POST; `get` GET                                                                                                                                                                                                                                                     | Customers submit/read own ratings; admin can read; staff is not allowed by this endpoint. Staff history instead returns rating fields from its own query. |
| `stats.php`                  | GET                                                                                                                                                                                                                                                                          | Admin-only stats.                                                                                                                                         |
| `get_notifications.php`      | list GET; `delete` POST                                                                                                                                                                                                                                                      | Admin-only notifications.                                                                                                                                 |
| `get_user_notifications.php` | GET                                                                                                                                                                                                                                                                          | Customer-only order notifications.                                                                                                                        |

The central client is `api` in [api.ts](../../frontend/src/api.ts#L74). It sets `credentials: 'include'` and JSON content type; mutations use POST. Confirm method and role in PHP before adding a new call—the table is a summary, not an API schema guarantee.

Key source anchors: [orders.php actions](../../backend/api/orders.php#L66), [auth actions](../../backend/api/auth.php#L7), [ratings.php](../../backend/api/ratings.php#L7), [request wrapper](../../frontend/src/api.ts#L63).

## Verified end-to-end paths

- **Checkout:** `Cart.checkout` → `api.createOrder` → `orders.php?action=create` → `products` (price/availability), `orders`, `order_items`, and `admin_notifications`. See [Cart.tsx](../../frontend/src/Cart.tsx#L106), [api.ts](../../frontend/src/api.ts#L91), [orders.php](../../backend/api/orders.php#L10), and [schema](../../database/knk_database.sql#L22).
- **Staff order history:** `StaffHistory` → `api.staffHistory` → `orders.php?action=staff_history` → `orders`, `order_items`, rider `users`, delivered-by `users`, and `order_ratings`; `OrderTable` renders the returned record. See [App.tsx](../../frontend/src/App.tsx#L2099), [api.ts](../../frontend/src/api.ts#L102), [orders.php](../../backend/api/orders.php#L100), and [OrderTable](../../frontend/src/App.tsx#L2910).
- **Delivery completion:** `RiderDashboard` → `api.riderStatus` → `orders.php?action=rider_status` → updates `orders.status`, `delivered_by_rider_id`, and `delivered_at`. See [App.tsx](../../frontend/src/App.tsx#L2349), [api.ts](../../frontend/src/api.ts#L124), and [orders.php](../../backend/api/orders.php#L256).
- **Customer rating:** `RatingModal` → `api.submitRating` → `ratings.php?action=submit` → inserts `order_ratings` after ownership/status/uniqueness checks. See [App.tsx](../../frontend/src/App.tsx#L1145), [api.ts](../../frontend/src/api.ts#L154), and [ratings.php](../../backend/api/ratings.php#L12).
