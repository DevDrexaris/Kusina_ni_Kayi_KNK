Kusina ni Kayi is a small local online food delivery system for XAMPP. It does not use cloud services or online payments.

## What I use?

- XAMPP with Apache and MySQL
- PHP 8+ (XAMPP's PHP)
- Node.js 18+
- VS Code 
- React Framework
- TypeScript
- Vite
- MySQL

## Features

Customers can register, log in, browse/search/filter the menu, manage a localStorage cart, place Cash on Delivery orders, and view order history/status. Administrators can view dashboard statistics, update order statuses, manage products/categories, and create Staff or Rider accounts from **Staff & riders**. Staff see active orders, assign available riders, and receive automatic refreshes. Riders see only their assigned orders and manually advance them through **Accepted → Picked Up → Out for Delivery → Delivered**. No maps, GPS, or external delivery service is used. Product prices and order totals are always recalculated by PHP from MySQL.
